# KVN Broadcast Control System 🏆

Программный комплекс для автоматизации графики и управления эфирным микшером **Blackmagic ATEM** во время трансляций КВН. Построен на базе фреймворка **NodeCG**.

## 🚀 Основные возможности

- **Инициализация игры:** Добавление команд, членов жюри, основной информации: названии игры, даты проведения, имени ведущего.
- **Управление титрами (Lower Thirds):** Динамический вывод имен жюри и названий команд с анимацией на основе GSAP.
- **Использование альфа-канала (Luma Key):** Использование альфа-канала (Luma Key) для прозрачности титров без стороннего софта.
- **Система подсчета баллов (Scoreboard):** Автоматизированное табло с парсингом данных из строки. Симуляция состояния табло после добавления. Добавление баллов по очереди для каждой команды, плавное отображение на экране.
- **Синхронизация данных на устройствах:** Использование архитектуры Replicants из NodeCG позволяет мгновенно синхронизировать данные сразу на всех устройствах, поэтому возможно управлять табло и титрами удалённо.
- **Архитектура Master-Scene:** Для вывода достаточно открыть одно окно, показываемый bundle управляется из панели управления.

## 🛠 Технологический стек

- Framework: Vue.js 3 (Options API)
- Animation: GSAP 3 (Timelines & Flip)
- Backend: NodeCG Replicants & Node.js
- Styles: CSS Clip-paths & Masking

## 🛠 Структура бандлов

- `kvn-file-upload`: Мастер-бандл (Backend), отвечающий за связь с оборудованием и системные настройки. В панель управления этого бандла загружается информация о жюри, командах, конкурсах.
- `kvn-lowerthird`: Управление плашками и титрами.
- `kvn-scoreboard`: Управление табло с баллами и результатами.

## 📦 Установка и запуск

1. Установите [NodeCG](https://nodecg.dev/) в папку.
2. Клонируйте этот репозиторий в ту же папку:
    ```bash
    cd название_корневой_папки
    git clone https://github.com/rinatitl/kvn-broadcast-system.git
    ```
3. Запустите NodeCG из корневой директории:
    ```bash
    nodecg start
    ```
4. Перейдите по сссылке `http://localhost:9090/`.
5. Во вкладке Graphics найдите и откройте master.html. Переместите окно с этой вкладкой на соседний монитор, откуда видеомикшер будет забирать графику. В связи с разницей удобных масштабов для панелей управления и графики, рекомендуется использование разных браузеров для точных настроек параметров масштаба.
6. Если подключаете инпут, который будет принимать альфа-канал, добавьте в конец адресной строки графики `?mode=key`.

## Работа с панелями управления

### `kvn-file-upload`

1. Введите название игры (оно будет отображаться на табло scoreboard).
2. Введите дату проведения игры.
3. Введите имя ведушего (оно будет доступно при выводе титров).
4. Добавьте конкурсы.
5. Добавьте жюри (дополнительная информация на титр — не обязательное поле).
6. Добавьте играющие команды (они будут доступны при выводе титров и при выводе табло scoreboard).

- Конкурсы, жюри и команды можно удалять и переименовывать. Все изменения автоматически отобразятся в других бандлах, в том числе на экране, если графика выведена.

Данные автоматически сохраняются в локальную базу. Для сохранения данных в формате JSON для последующего использования на другом устройстве используется система **экспорта и импорта JSON-строк**.

- **Экспорт**: В самом низу бандла кнопка «Сформировать и выгрузить данные» позволяет экспортировать информацию об игре в JSON-строку, которая появится в поле ниже кнопки.
- **Импорт**: Вверху бандла выпадающее меню под кнопкой «Импортировать JSON» скрывает поле для вставки JSON-строки и кнопку «Подгрузить данные из строки».
- **Очистка базы данных**: Для удаления всех данных используется красная кнопка в верхней части бандла.

### `kvn-lowerthird`

1. В верхней части бандла компоненты связаны с графикой и выводом титров в эфир:
    - Полоска под строкой «Управление состояниями» работает в режиме 3 цветов: `серый` – мастер-сцена настроена на другой бандл; `зеленый` – мастер-сцена настроена на текущий бандл, графика готова к выводу в эфир; `красный` – графика в эфире.
    - Кнопка `Prepare` переключает `master.html` в режим сцены Lowerthird, то есть графика готова к выводу в эфир. Полоска должна стать зеленой.
    - Кнопка `Play In` запускает анимацию появления титра. Титр не уйдет до момента нажатия на кнопку `Play Out` или `Clear Screen`.
    - Кнопка `Play Out` запускают анимацию ухода титра.
    - Кнопка `Clear Screen` мгновенно убирает графику из кадра.
    - Кнопки `5 sec`, `7 sec` и `..sec` запускают анимацию появления титра и автоматически запускают анимацию ухода титра по истечении времени, указанного на кнопке. Дополнительное поле предназначено для самостоятельного вписывания времени. При запуске титра на определенное время, под строкой «Управление состояниями» появляется счетчик, сообщающий о времени до конца показывания титра.
    - В разделе `Отправлено в титры` отображаются данные, которые титр принял для вывода в эфир. Можно проверить выводимый текст до выхода графики на экран.
2. В нижней части бандла кнопки позволяют отправлять данные ведущего, члена жюри или команды в эфир:
    - К названиям команд титровальня подставляет `Команда КВН «»`
    - Есть возможность отправить незапланированный титр с помощью соответствующих полей внизу и кнопки «Отправить пользовательский титр»
3. Для правильного вырезания титра используется версия графики с `?mode=key`. Для переключения режима отображения необходимо добавить это выражение в конец адресной строки. Оба варианта графики должны работать синхронно, однако возможны некоторые задержки.

### `kvn-scoreboard`

1. В верхней части бандла компоненты связаны и выводом табло с баллами в эфир.
    - Полоска под строкой «Управление состояниями» работает в режиме 3 цветов: `серый` – мастер-сцена настроена на другой бандл; `зеленый` – мастер-сцена настроена на текущий бандл, графика готова к выводу в эфир; `красный` – графика в эфире.
    - Кнопка `Prepare` переключает `master.html` в режим сцены Scoreboard, то есть графика готова к выводу в эфир. Полоска должна стать зеленой.
    - Кнопка `Play In` запускает анимацию появления титра. Титр не уйдет до момента нажатия на кнопку `Play Out` или `Clear Screen`.
    - Кнопка `Clear Screen` мгновенно убирает графику из кадра.
2. В нижней части бандла кнопки позволяют управлять начислением баллов и голосов, а также симулировать начисление баллов для проверки
    - В поле «Ввести данные» можно вставить скопированные данные из гугл таблицы. Нажатием на кнопку `→` вызывается функция парсинга, которая распределяет введенные данные по командам. Во всплывающем модальном окне возможно сверить начисляемые баллы. Кнопка `Ввести данные` распределит баллы по полям рядом с командами
    - В импровизированной «таблице» присутствует 3 столбца, в которые возможно вносить данные
        - Количество голосов, которые влияют на положение команды в итоговом рейтинге при одинаковом количестве баллов. Очистить поля от нулей можно нажатием на заголовок `Голосов ×`
        - Количество итоговых баллов меняется исходя из добавляемых баллов, но при необходимости можно внести изменения в ручном режиме. Обнулить баллы можно нажатием на заголовок `Итоговые баллы 0`
        - Количество добавляемых баллов в текущем раунде и кнопка `+`, инициирующая анимацию добавления баллов и подсвечивания команды на табло. Очистить поля от уже введенных баллов можно нажатием на заголовок `Добавить баллы ×`
    - Для удобства начисления баллов в порядке от команды с меньшими баллами к большей есть кнопка сортировки. Когда кнопка белая, это значит, что сортировка включена, и команды расположены именно в том порядке, в котором они расположены на табло, включая голоса.
    - Для предварительного просмотра итога начисления баллов имеется желтая кнопка симуляции начисления, которая складывает имеющиеся итоговые баллы и баллы в полях `Добавить баллы`. Положение команд после начисления будет показано во всплывающем окне.
